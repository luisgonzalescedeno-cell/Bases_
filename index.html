¿Qué es Mongoose?

Un traductor entre tu código y MongoDB

Mongoose es una librería de Node.js que sirve para trabajar con MongoDB desde código JavaScript, de forma ordenada. Es un ODM (Object Document Mapper): traduce entre los documentos de MongoDB y los objetos de tu programa.

Esquema de colección

Define los campos de la colección usuario y su tipo de dato, y exporta el modelo USER.

.js
var mongoose = require('mongoose');
var usuarioSchema = mongoose.Schema({
_id: Number,
usuario_user: String,
nombre_user: String,
apellidos: String,
email:String,
contrasena:String
});
var USER = mongoose.model('usuario', usuarioSchema);
module.exports = USER;
